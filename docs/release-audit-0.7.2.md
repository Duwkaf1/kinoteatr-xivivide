# Проверка готовности Yoru 0.7.2

25 октября 2026 года, Asia/Yekaterinburg. Задача: убрать подпись источника фото с карточек и проверить плееры, озвучки, загрузку аниме перед широкой публикацией.

**Вывод: для обещания «любое аниме открывается и работает автоматически» приложение пока не готово.** Можно тестировать его как ранний плеер для прямых ссылок и отдельных страниц сайтов. Успешные тесты движков не означают, что подключены каталоги видео и работают все реальные записи студий.

## Что изменено

- Подпись «Фото · AniDB» и аналогичные подписи источников фото убраны с карточек. Сведения об источниках сохранены в документации и данных выбора фотографии.
- Исправлено сохранение намерения воспроизведения при смене движка во время загрузки. Первоначально при загрузке `video.paused` истинно даже без ручной паузы; это больше не переносится как команда пользователя остановить видео.
- Исправлено закрытие оформленных субтитров вместе с Video.js. Сначала освобождаются субтитры, затем движок. Дополнительно учитывается переподчинение video/canvas в DOM: очистка libass однократная, ошибки `removeChild` и повторного завершения worker не маскируются общим подавлением исключений. Пакет зависимости не изменялся.

## Что проверяют сценарии

| Область | Проверка |
| --- | --- |
| Основной и альтернативный плееры | Настоящие MP4 H.264/AAC, WebM VP8/Opus и HLS H.264/AAC; время видео движется, счётчик декодированного аудио увеличивается |
| Русские студии | Метаданные AniDUB, AniLibria и другой русской студии выбираются по приоритету; иностранные и другие качества не подставляются |
| Оригинал | Японские источники выбираются отдельно; ручная пауза, звук и позиция сохраняются при смене движка |
| Восстановление | HTTP 503, повторные попытки, разрешённый резерв, фиксированное качество, тайм-аут загрузки, следующая серия |
| Субтитры | Разные тексты переводов, текстовые дорожки и реальный libass WASM/canvas; повторная смена движков с активным оформленным переводом и закрытие без оставшегося canvas/video |
| Electron | Реальный `file://` renderer, оба движка на MP4/HLS, звук декодируется, оригинал и очистка; первоначальный WebM/ASS сценарий также сохранён |
| Остальное | Темы и своя палитра, заметки и фото, библиотека, сохранение, клавиатура и размеры окна |

Тестовое медиа создано FFmpeg: чёрный кадр и синусоидальный тон. Названия студий и языки в этой проверке — **метаданные**, не реальные записи AniDUB/AniLibria и не проверка качества речи или перевода. Приложение не распознаёт язык звука автоматически. Стандартный HTTP Range-сервер тестовых MP4/WebM обеспечивает проверяемую перемотку; реальные серверы могут иметь другие ограничения.

После исправлений полный Linux-прогон завершился успешно: **46 unit-тестов и 44 браузерных сценария**, production build и настоящий Electron. В Electron отдельно подтверждены оба движка с H.264/AAC MP4/HLS, счётчик декодированного звука, режим оригинала, удаление элементов видео/субтитров и закрытие приложения. Скриншоты галереи пересняты, подписи источника фотографии отсутствуют. Исходные неуспешные прогоны выявили ошибки; в итоговый результат они не выдаются за успешные.

Новые собственные MP4/HLS fixtures сохранены в `test/fixtures/playback`, используются также в Windows CI и не входят в дистрибутив. Прежние сценарии продолжают проверять ограниченные попытки, паузу, ожидание, качество и переключение серий.

## Живые проверки сайтов

Запросы выполнены через унаследованный прокси с обычной проверкой TLS, без логина, обхода CAPTCHA, изменения доверия сертификатам или обхода сетевых ограничений. Чтение HTML/JSON ограничено по размеру. [Машинный отчёт](release-audit-0.7.2.json).

| Адрес / сервис | Результат | Что это доказывает |
| --- | --- | --- |
| `old.yummyani.me/catalog?page=5` | HTTP 200 | Каталог доступен, воспроизведение не подтверждено |
| `animejoy.ru` | HTTP 200 | Главная доступна, воспроизведение не подтверждено |
| `anidub.com` | HTTP 200 | Главная доступна, записи озвучек не проверены |
| `aniliberty.top` | HTTP 200 | Получена часть HTML, видео не проверено |
| AniLibria API каталога | HTTP 200 | Публичные метаданные доступны |
| AniLibria API релиза 8452 | HTTP 200, 357 записей эпизодов | Получен список «Блича», а не просмотрены 357 серий |
| Первый 1080p HLS этого релиза, `cache.libria.fun` | CONNECT 403 | Среда не получила манифест; живое воспроизведение не подтверждено |
| Присланный TroutCDN `/283290` | HTTP 403 | Эта страница недоступна из текущей среды |
| Присланный Brogiro `/series/283290/` | HTTP 404 | Этот адрес не найден при проверке |
| `kinopoisk.cx/series/749374/` | CONNECT 403 | Адрес блокируется сетью среды |

Результаты могут отличаться на пользовательском IP/VPN. HTTP 200 страницы не подтверждает наличие рабочего видео, нужной серии, студии или независимого резерва. Первый HLS-запрос не дошёл до видеосервера, поэтому сегменты реального аниме здесь не скачивались и не декодировались.

Адрес `cache.libria.fun` сохранён дополнением в черновик разрешённых доменов среды. Сохранение черновика не применяет доступ: для повторной живой проверки нужно сохранить настройки сети и опубликовать среду. Обходить ограничение другим маршрутом нельзя.

## Что остаётся до выпуска «установил и смотри»

1. Подключить получение видеокаталога, серий, студий, переводов и доступных источников. Сейчас поиск AniLibria выбирает постеры, не добавляет автоматически видеопотоки; страницы сайтов открываются отдельно.
2. Проверить адаптеры на живых релизах, реальное соответствие звука/субтитров, монтажей и выбранного качества. Обновление истёкших ссылок и независимые резервы сейчас не реализованы.
3. Проверить длительный просмотр и смену серий на разных Windows-компьютерах/сетях, работу Discord и физическое масштабирование/мониторы. Автотесты и короткие fixtures этого не заменяют.

Общедоступную сборку следует обозначать как предварительную, с этими ограничениями. Обещания «все аниме», «никогда не зависнет» или «все озвучки подтверждены» результатами проверки не обоснованы.
