# Yoru 0.7 — система интерфейса и проверка редизайна

## Направление и границы

Личный кинозал: спокойные нейтральные поверхности, выразительные постеры, чёткая иерархия и один сдержанный акцент. Существующее Electron-приложение сохранено, миграции фреймворка нет. Применён предоставленный скилл Windows UI/UX Pro: изучен его основной `SKILL.md`. Перечисленные в нём `references/*.md` не были доступны через провайдер; их содержимое не выдаётся за прочитанное.

Стек: Electron 45, Vite 8, HTML/CSS и JavaScript. Для просмотра используются HTML5/HLS.js, Video.js/VHS и libass-wasm. Отдельные окна чужих сайтов и AniDB сохраняют собственный интерфейс сайта и системную рамку Windows. Их CSS и ограничения не подменялись. Профиль, библиотека, настройки, прогресс, переводы, персонажи и личные заметки совместимы с прежней версией.

До работы создана ветка `backup/before-fluent-redesign-0.6.3`, коммит `59750e2`. Это точка отката приложения до редизайна.

## Дизайн-система

Палитры находятся в `src/themes.css`, компоненты — в `src/design-system.css`; `src/style.css` только подключает их. Старые слои переопределений удалены. Компоненты используют роли фона, поверхности, текста, границы и акцента, а не отдельные цвета для каждого экрана.

| Роль | Тёплая ночь | OLED | Молочный |
| --- | --- | --- | --- |
| Фон | `#151617` | `#000000` | `#f4f3ef` |
| Поверхность | `#1d1f21` | `#0e0f10` | `#fffefa` |
| Текст | `#f2f1ed` | `#f5f4f0` | `#282a29` |
| Акцент | `#e5bf88` | `#d5c8a7` | `#4b604c` |

Также сохранены «Север», «Сакура» и «Своя». У собственной темы по-прежнему настраиваются фон, панели, текст, акцент и скругление 12–36 px. Низкий контраст вызывает подсказку, цвет текста основной кнопки вычисляется. Редактор сохраняет читаемую палитру, даже если пользователь выбрал неудачные цвета. Переключение готовых тем не стирает свои значения. OLED применяется до первого отображения страницы и сохраняется после перезапуска.

Шрифт — системный Segoe UI Variable с Segoe UI/Arial в качестве запасных. Заголовок страницы 30 px, заголовки разделов 18–22 px, основной текст/кнопки 13–14 px. Подписи 11–12 px. Сохраняется пользовательский размер текста 90–120%. Основной шаг отступов — 4/8 px. Боковая панель 220 px, на узких окнах — 72/64 px; основные действия высотой 40 px, компактное управление плеером 36 px. Базовый радиус карточек 20 px; радиус полей и кнопок вычисляется из общей настройки.

У кнопок определены обычное, наведённое, нажатое, отключённое и клавиатурное состояния. Движение занимает 100–180 мс, без постоянно работающих фоновых анимаций. Настройки пользователя, режим «Экономия» и `prefers-reduced-motion` отключают эффекты. `forced-colors` использует системные цвета фокуса и выделения. Декоративных emoji нет: элементы управления используют собственные SVG.

## Окна, клавиатура и масштаб

Минимальное окно Electron теперь 640×480 вместо 960×680; длинные страницы прокручиваются. На узком размере навигация превращается в панель иконок с доступными именами и подсказками, поля/карточки меняют число колонок, диалоги ограничены высотой окна и прокручиваются внутри. Системные рамка и кнопки окна не заменялись самодельными.

Есть ссылка «Перейти к содержимому» для клавиатуры, заметный `:focus-visible`, штатный Escape в диалогах и возврат фокуса к открывшей кнопке. Переходы по группам настроек ставят фокус на группу; раздел «Подробно» открывается перед переходом. Горячие клавиши плеера не перехватывают ввод в полях.

Проверки масштаба используют два способа: Chromium с deviceScaleFactor 1/1.25/1.5/2 и соответствующим уменьшением доступного CSS-размера окна; настоящий Linux Electron с zoom 100/125/150/200%. Также проверен размер окна Electron 640×480. Это проверка рендерера и адаптивной верстки, **не физическая смена DPI монитора Windows**. Реальные Windows DPI, ClearType, многомониторный переход и захват звука Discord требуют пользовательской Windows-среды.

## Основные файлы

- `src/themes.css`, `src/design-system.css`, `src/style.css` — токены и компоненты.
- `index.html` — оболочка, навигация настроек, OLED, доступные имена диалогов.
- `src/app.js`, `src/icons.js` — собственные постеры в hero, SVG и переходы между группами.
- `src/preferences.js`, `public/theme-init.js` — сохранение и раннее применение OLED.
- `desktop/main.js` — минимальный размер окна и фон до загрузки.
- `e2e/app.spec.js`, `scripts/smoke-desktop.js`, `test/preferences.test.js` — проверки редизайна, тем, контраста, масштаба и регрессий.

## Проверки и ограничения

Команды: `npm test`, `npm run test:e2e`, `npm run build`, `npm run test:desktop`. Windows-пакет создаётся `NODE_USE_ENV_PROXY=1 npm run package:win`, ZIP — `python3 scripts/archive-win.py`; официальные проверки Electron и TLS не отключаются.

Для пяти готовых палитр автоматически проверяются контраст обычного/вторичного текста на странице и панели и текст основной кнопки (не ниже 4.5:1). Пользовательские цвета не принудительно заменяются; для них остаётся предупреждение в редакторе. Браузер проверяет все шесть вариантов оформления, длинные названия, навигацию, переключатели, поля, диалоги и состояния. Сценарии видео, двух плееров, оригинальной озвучки, субтитров и сохранения заметок также выполняются.

Снимки создаются из подготовленной библиотеки с настоящими постерами и архивными фото; приложение устанавливается пустым. Видео на снимках — короткий собственный тестовый фрагмент. [Галерея и происхождение изображений](images/README.md).

Принципы Fluent применены в рамках Electron: иерархия поверхностей, спокойное выделение, системная типографика, плотность, клавиатура и адаптация. Нативные WinUI/Mica-компоненты не заявляются. Платные зависимости, внешние дизайн-сервисы и водяные знаки не добавлены. Шрифты Windows используются из системы, новые шрифты без лицензии не распространяются.

Справочные страницы Microsoft: [Fluent](https://fluent2.microsoft.design/), [Windows app design](https://learn.microsoft.com/windows/apps/design/), [Typography](https://learn.microsoft.com/windows/apps/design/style/typography). Их текущие веб-версии в этой среде отдельно не проверялись.
