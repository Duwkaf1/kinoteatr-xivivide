# Yoru 0.8.2 — удаление и резервные постеры

В этой версии добавлена кнопка **Настройки → Дополнительно → Удалить приложение полностью**. Она доступна в версии, установленной актуальным Windows-установщиком. Появляется системное подтверждение с отменой по умолчанию. После подтверждения Yoru закрывается и запускает свой деинсталлятор. Он удаляет приложение, локальные библиотеку, историю, заметки, темы и кэш. Обычное удаление через Windows по-прежнему сохраняет профиль.

Профиль удаляется только из фиксированной папки `%APPDATA%\kadr-anime`. Другие файлы, добавленные пользователем в папку установки, не входят в удаляемый список. Ссылки и junction внутри профиля удаляются как ссылки без перехода к их целям. Режим запуска с отдельным профилем и ZIP без установщика не могут запустить полное удаление из приложения. Отмена или ошибка запуска не закрывают Yoru.

Если постер Yummyani отсутствует или не загружается, приложение запрашивает точную карточку этого релиза и проверяет резервную обложку:

1. AniLibria: точный alias, совпадение всех предоставленных MAL/Shikimori ID и папки постера с ID релиза.
2. MyAnimeList через Jikan: только явный `myanimelist_id` этого релиза, совпадение `mal_id` ответа и официальный CDN изображений.

Название не используется для автоматического сопоставления. Другой сезон, противоречивые идентификаторы, отсутствие точной связи или недоступность резервов оставляют заглушку. Абсолютную безошибочность внешних метаданных гарантировать нельзя; приложение не подменяет их догадками. AniDB HTTP-клиент для этой функции не требуется.

Замена изображения сохраняет возрастную отметку и кнопку просмотра. Запоздавший ответ не заменяет изображение другого аниме или нового каталога. Сеть ограничена фиксированными публичными API, тайм-аутами и двумя одновременно выполняемыми запросами резервных обложек. Открытая карточка получает приоритет; удалённые результаты поиска и фон при открытии карточки освобождают очередь. Это исправляет задержку постера за медленными невидимыми запросами.

В комплекте сохранены поиск, фильтры, случайный выбор, оба каталога, темы, два встроенных движка, субтитры и личные заметки. Тексты установщика и памятки обновлены под реальный каталог.

Текущий отчёт о проверках, Windows CI, установщик и скриншоты: README.md и docs/validation.md в репозитории GitHub `Duwkaf1/kinoteatr-xivivide`. Браузерные проверки используют собственные медиа и контролируемые отказы; они не являются доказательством работы всех внешних сайтов, аниме и сетей РФ.


## Проверки

Код приложения и упаковки — `3d4f6325697d2a4787d2a6292f7ff7be7e2bad5d`. Пройдены 80 unit-тестов, production build и настоящий Linux Electron. 22 отдельных браузерных сценария проверяют каталог, резервные постеры, точные соответствия, конфликтующие сезоны, второй отказ источника, приоритет выбранной карточки и состояния кнопки удаления.

Полный браузерный прогон завершился успешно: **93 сценария за 5,1 минуты**. Проверены смешанные нажатия, поиск/фильтры/случайный выбор, каталоги, баннер и геометрию месяца, все темы, малые окна и масштаб 100/125/150/200%, оба движка, звук, субтитры, прогресс, персонажей и настоящее ожидание 30 секунд при отказе источника. Числа и итог Windows CI указаны в [истории проверок](validation.md).

Основной CDN был намеренно отключён, ответы метаданных и резервных изображений не подменялись. Работа ветки MyAnimeList проверена на контролируемых ответах; все живые релизы и сети РФ не объявляются проверенными.
