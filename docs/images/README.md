# Yoru — скриншоты интерфейса

Галерея содержит **47 PNG** интерфейса. 43 воспроизводимых снимка пересозданы для 0.8.1: полный прогон 86 браузерных сценариев и повторный прогон 16 сценариев каталога после последних исправлений. Ещё четыре снимка — живой каталог, фильтры и воспроизведение в Linux Electron без подмены API/медиа. Старый экран «Источники» удалён вместе с его снимком.

## Повторить снимки

После успешного полного `npm run test:e2e` выполни `node scripts/update-gallery.js`. Скрипт сначала проверяет наличие всех 43 воспроизводимых снимков и затем копирует их в галерею. Четыре `catalog-live-*.png` он не заменяет: они получены отдельным живым прогоном и требуют повторной проверки настоящего сервиса. Для персонажей используется подготовленный состав с фотографиями (`character-photos.png`), а не диагностический экран ручных отметок серий.
