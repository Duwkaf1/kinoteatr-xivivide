# Актуальные снимки Yoru 0.5.0

Все PNG в этой папке пересняты из текущего интерфейса. Старые снимки с буквами и неоднородным фоном удалены.

- `library.png` — библиотека с настоящими постерами аниме.
- `poster-picker.png` — поиск и выбор обложки.
- `settings-cream.png`, `settings-sakura.png` — готовые темы.
- `settings-custom.png` — собственная палитра.
- `settings-manual.png` — подробные ручные настройки.

Снимки создаются браузерными тестами из подготовленных данных. Начальная библиотека приложения пустая; показанные видеоссылки — тестовые. Обложки получены из каталога AniLibria, права принадлежат их правообладателям. Подробнее: [posters.md](../posters.md).
