# Актуальные снимки Yoru 0.6.3

Все PNG в этой папке пересняты из текущего интерфейса. Старые снимки с буквами и неоднородным фоном удалены.

- `library.png` — библиотека с настоящими постерами аниме.
- `poster-picker.png` — поиск и выбор обложки.
- `settings-cream.png`, `settings-sakura.png` — готовые темы.
- `settings-custom.png` — собственная палитра.
- `settings-manual.png` — подробные ручные настройки.
- `original-player.png` — компактный плеер с русскими подписями и переводом с оформлением поверх тестового видео.
- `player-settings.png` — отдельное окно параметров просмотра.
- `anidb-cast.png` — персонажи Arcade Gamer Fubuki, редактируемое имя, личная заметка и фото сэйю: сведения из архивного AniDB XML релиза 128, изображения с CDN AniDB. Полный состав сезона/серий снимком не подтверждается.

Снимки создаются браузерными тестами из подготовленных данных. Начальная библиотека приложения пустая; показанные видеоссылки — тестовые. Обложки получены из каталога AniLibria, права принадлежат их правообладателям. Подробнее: [posters.md](../posters.md).

Фотографии персонажей и актёров принадлежат их правообладателям. Источник архива и проверка CDN описаны в [character-photos.md](../character-photos.md). В установочный пакет эти тестовые изображения не включены.
