# Yoru — скриншоты интерфейса

Галерея содержит **55 PNG**. 49 воспроизводимых снимков пересозданы для 0.9.0 полным прогоном браузерных сценариев. Ещё шесть — живой каталог, фильтры, воспроизведение и два проверенных резервных постера. Для резервных постеров отказ основного CDN намеренно вызван тестом; метаданные и альтернативные изображения настоящие. [Результат](../live-posters-0.8.2.json).

## Повторить снимки

После успешного полного `npm run test:e2e` выполни `node scripts/update-gallery.js`. Скрипт сначала проверяет наличие всех 49 воспроизводимых снимков и затем копирует их в галерею. Шесть `catalog-live-*.png` он не заменяет: они получены отдельным живым прогоном и требуют повторной проверки настоящего сервиса. Для персонажей используется подготовленный состав с фотографиями (`character-photos.png`), а не диагностический экран ручных отметок серий.
