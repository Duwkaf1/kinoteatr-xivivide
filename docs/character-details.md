# Свой состав, имена и заметки — Yoru 0.7.1

Панель «Персонажи» относится к открытому аниме и выбранному сезону. Над карточками видны оба названия. Связь с AniDB ID хранится у самого аниме для каждого сезона; XML другого релиза отклоняется. В новой библиотеке нет заранее подставленного состава. Данные нужно импортировать или загрузить через собственный зарегистрированный HTTP-клиент AniDB. Полная автоматическая загрузка всех аниме и полный состав каждой серии пока не реализованы.

В 0.7.1 технические действия убраны из панели: на виду только карточки, заметки и «Настроить». Изменение имени и заметки не требует открывать это окно.

## Как пользоваться

1. Нажми карандаш рядом с именем персонажа. Укажи свою подпись и нажми «Сохранить имя». В окне всегда видно исходное имя AniDB.
2. Под именем введи текст в строку «Добавить заметку…». Поле расширяется при фокусе. После паузы 400 мс или ухода из поля появится «Сохранено». Отдельной кнопки для заметки не нужно.
3. Для возврата имени нажми «Исходное имя», затем «Сохранить имя». Заметка при этом остаётся. Чтобы удалить заметку, очисти её поле.

Имя — до 160 символов, заметка — до 500. Текст показывается буквально, без выполнения HTML. Поля не перехватывают горячие клавиши плеера, смена подписи не перезапускает видео. Подпись в ручном списке персонажей серии также обновляется. Поиск фотографии продолжает использовать исходное имя, чтобы личное прозвище не ухудшало результаты.

## Где сохраняются записи

Имена и заметки хранятся локально в профиле приложения, отдельно от обновляемого AniDB-кэша. Ключ записи включает ID аниме в библиотеке, ID релиза AniDB и ID персонажа. Одинаковое имя или даже одинаковый релиз у двух разных записей библиотеки не смешивают личные подписи. Другой релиз сезона получает отдельные записи; исходные имена и связи AniDB не меняются.

Обновление/повторный импорт XML и вытеснение состава из ограниченного кэша не удаляют записи. Когда тот же состав с теми же ID снова загружен, личные подписи появляются вновь. Если источник сменит ID персонажа, подписи не угадываются по имени и не переносятся автоматически. Изменение ID аниме в импортируемой библиотеке тоже создаёт другую привязку. Перенос одного списка видеоссылок не переносит локальные заметки; профиль нужно сохранять отдельно.

При ошибке записи поле сохраняет набранный текст и показывает ошибку вместо «Сохранено». После восстановления места можно снова войти и выйти из поля для повторной записи. Пока сохранить не удалось, не закрывай приложение. Повреждённое хранилище личных подписей не перезаписывается автоматически.

## Проверки

Unit-проверки подтверждают раздельные записи для разных аниме/релизов/персонажей, восстановление после перезапуска хранилища, сохранность при замене/вытеснении кэша, ограничения текста, отказ записи и защиту повреждённого хранилища. Браузер проверяет редактирование имени, заметку прямо под ним, обновление XML, переключение двух аниме с одним AniDB ID, другой сезон, перезагрузку, возврат исходного имени и повторную запись после ошибки. Видео при редактировании остаётся тем же элементом и на паузе.
