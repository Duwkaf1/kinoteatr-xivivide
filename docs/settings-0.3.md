# Темы и настройки 0.3

Локальная подготовка 24 октября 2026 года. Новая версия не отправляется в открытый GitHub-репозиторий до подтверждения приватности. Переход в private отдельно запрошен пользователем. Первоначально API блокировался сетью; после применения разрешения `api.github.com` чтение состояния заработало, но PATCH `private=true` вернул HTTP 403 `Resource not accessible by integration`. Интеграции не хватает прав на смену видимости. Сохранение локальных файлов не меняет видимость GitHub.

## Изменения

- Четыре полные темы: Тёплая ночь, Север, Сакура, Молочный. Светлая тема меняет не только акцент: фон, панели, текст, поля, диалоги и состояния выбора используют свою палитру.
- Более округлые карточки, кнопки, панели и диалоги. Настройки доступны отдельной кнопкой в боковой панели.
- Три режима производительности с разными буферами HLS, разрешением по умолчанию, порциями карточек и эффектами. Подробнее в таблице README.
- Отдельный выбор разрешения; автоматического снижения при сбое нет. Новый режим не перезапускает текущее видео, его параметры фиксируются на время серии.
- Настройки анимаций и автоматического перехода к следующей серии. Системное уменьшение движения и экономный режим имеют приоритет над анимациями.
- Независимое хранение предпочтений, совместимость с библиотекой/историей прошлых версий и старой настройкой эффектов. Сохранение качества работает даже до добавления первого аниме.

## Проверка

Прошли `npm test` (15 тестов), `npm run test:e2e` (16 сценариев), production-сборка и `npm run test:desktop` с виртуальным Xorg на Linux. Desktop-проверка запускает настоящие production-файлы через `file://`, меняет тему/режим, перезапускает страницу, проверяет сохранение настроек, воспроизводит собственное WebM и проверяет изоляцию окон.

Тесты дополнительно проверяют отсутствие перезапуска/снятия с паузы текущего видео при смене режима, выбор новой настройки на следующем запуске, независимую работу ручной следующей серии при выключенном автопереходе и уменьшение количества отображаемых карточек в экономном режиме.

Windows-пакет и ZIP собираются локально. Прогона 0.3 на Windows CI нет, поскольку новую версию пока не публикуют. Звук Discord, живые внешние сайты, фактическая нагрузка на конкретном ПК и длительный тест памяти не проверены этой задачей.

## Дополнение 0.3.1: собственная тема

Добавлены четыре пользовательских цвета и скругление 12–36 px, мгновенный предпросмотр, сохранение/восстановление и сброс только своей палитры. Готовые темы не стирают пользовательскую. Основной текст проверяется по контрасту с фоном и панелями; цвет надписи основных кнопок выбирается автоматически. Неверные HEX-коды не применяются, произвольный CSS/HTML в сохранённых настройках не принимается.

README теперь начинается с отдельного скриншота редактора `docs/images/custom-theme-0.3.1.png`. Он имеет новое имя и не подменяет старый скриншот библиотеки.
