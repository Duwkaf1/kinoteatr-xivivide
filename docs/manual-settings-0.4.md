# Ручные настройки 0.4

25 октября 2026 года. Добавлены самостоятельные параметры буфера, восстановления, студий, звука, скорости, перемотки и интерфейса. У каждого числового значения есть диапазон, проверка перед сохранением и нормализация при чтении старого/изменённого JSON. Параметры хранятся отдельно от библиотеки, своей темы и истории.

Для HLS ориентир размера и длительности буфера не является жёстким лимитом всей памяти: HLS.js может хранить целые сегменты, а декодер, DOM и Electron используют собственную память. Для прямого MP4 буфер контролирует Chromium. На нагрузку процессора влияют кодек и фактическое разрешение потока. Настройки не обещают измеренный процент ускорения на конкретном ПК.

`PlaybackPlan` теперь получает ограниченное число попыток и правила студий/автосмены. При этом фильтры `language: ru` и точного разрешения сохраняются. Каждый запуск серии получает собственные копии параметров, поэтому изменение настроек не меняет текущий план восстановления и HLS-экземпляр.

Начальная загрузка без метаданных имеет отдельный таймер. Он снимается при получении метаданных, остановке/закрытии, смене серии и при ручной паузе. Таймер обычного зависания работает только во время воспроизведения. Отложенные события старого источника проверяют поколение плеера и не могут перезапустить закрытую серию.

Проверки включают реальные перехваченные запросы: отключённая автосмена действительно ограничивается тремя попытками первого источника; запрос без ответа восстанавливается по выбранному пятисекундному ожиданию; приоритет AniLibria выбирает соответствующий поток, не запрашивая AniDUB. Громкость/скорость проверяются на свойствах настоящего video без пересоздания элемента и без снятия с паузы. Ручная библиотека на 40 записей выводит 12 карточек, сохраняет параметры после перезапуска и остаётся без горизонтального переполнения на 960 px с текстом 120%.

Изменения подготовлены локально. GitHub-репозиторий на момент начала задачи всё ещё public; интеграция ранее получила HTTP 403 при попытке сделать его private. Новая версия не отправляется в открытый репозиторий до выполнения запроса пользователя о приватности. Настройки программы не управляют видимостью GitHub. Сайтовые адаптеры и звук Discord не добавлены этой задачей.

## Результат проверки

Прошли 24 unit-теста и 22 браузерных сценария. При desktop-проверке найден сброс сохранённой скорости при новой загрузке ресурса; исправлено применение `defaultPlaybackRate` и скорости после метаданных. После исправления прошла настоящая Electron-проверка с отдельным временным профилем и повторены три затронутых браузерных сценария: сохранение ручных параметров, новая загрузка с выбранной скоростью/громкостью и восстановление запроса без метаданных. Native-проверка подтверждает сохранение буфера/числа попыток, фактические свойства video `volume: 0.55`, `playbackRate: 1.25` и воспроизведение собственного WebM.

Production-сборка создаётся без изменения lockfile. Windows-пакет собирается из неё и архив проверяется на целостность. Реального прогона версии 0.4 на Windows и проверки звука Discord не было. Предупреждение сборщика относится к размеру отдельного HLS-модуля, который загружается по требованию.
