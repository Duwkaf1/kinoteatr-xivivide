# Yoru 0.8.1 — поиск, фильтры и расширенный каталог

## Что изменилось

На странице каталога убрана кнопка «Найти аниме» из шапки: поиск находится прямо на странице. На остальных экранах кнопка возвращает к каталогу.

В режиме «Качество» неподходящие карточки плавно исчезают при вводе, оставшиеся перестраиваются, новые мягко появляются после ответа сервера. При очистке поиска результаты возвращаются. В других режимах и при уменьшении движения декоративные переходы отключены. Изображения совпадающих карточек используются повторно.

Фильтры позволяют выбрать до шести жанров и возрастной рейтинг. Несколько жанров означают пересечение: аниме должно соответствовать всем выбранным. Выбранные фильтры учитываются при поиске, смене сортировки, подгрузке следующей страницы и случайном выборе. Сброс фильтров сохраняет введённое название. На обложках и в карточке отображаются возраст и жанры из метаданных.

Для большого списка жанров есть отдельный поиск. Возрастные шкалы зависят от источника: AniLibria использует 0+/6+/12+/16+/18+, Yummyani — G/PG/PG-13/R-17+/R+. Приложение не приписывает им одну общую систему классификации.

## Два каталога и два способа просмотра

В поле «Где искать» можно выбрать:

- **AniLibria** — встроенный просмотр, сохранение серии и тайминга, два движка. Число 1 904 относится только к этому каталогу.
- **Yummyani** — дополнительный каталог с собственными жанрами, возрастами, поиском, сортировкой и случайным выбором. При нажатии «Смотреть на Yummyani» нужная страница открывается в отдельном изолированном окне Yoru. Ссылку вводить не надо. Серии, озвучку, субтитры и прогресс в этом режиме контролирует сайт; приложение не заявляет их синхронизацию со встроенным плеером.

Yummyani не сообщает общее число в использованном API: интерфейс показывает количество загруженных карточек, а не выдуманный размер каталога. Каталоги не объединяются суммой: релизы между ними могут повторяться. При переключении источника название сохраняется, жанры и возраст сбрасываются, чтобы несовместимые идентификаторы не давали неверные результаты.

## Случайный выбор

Встроенный каталог выбирает позицию из всего найденного набора, затем запрашивает нужную страницу, а не выбирает только среди видимых карточек. Для Yummyani используется его серверная случайная выборка с теми же условиями. Повторное нажатие во время запроса заблокировано, смена условий или уход со страницы отменяет устаревший выбор. Если результатов нет, показывается понятное сообщение.

## Защита от ошибок интерфейса

Поиск отменяет устаревшие запросы и проверяет номер актуального запроса перед изменением сетки. Кнопка следующей страницы скрывается при изменении условий, чтобы предыдущая страница не дополнила новый поиск. Уход со страницы во время запроса не оставляет каталог в состоянии вечной загрузки. Запросы жанров также отменяются при смене провайдера.

Сетевой шлюз принимает типизированные операции и только фиксированные официальные адреса API, без произвольных URL. Для Yummyani используются только публичные GET-запросы без аккаунтов, токенов и заимствованного ключа веб-приложения. Код и рекламные скрипты сайта не встраиваются в основной интерфейс. Окно сайта не получает Node.js и API профиля Yoru.

На финальном коде приложения `0197575831ddb7ee05a606f6cb514c8962739805` пройдены **72 unit-теста**, production build и настоящий Linux Electron. Полный прогон содержит **86 успешных браузерных сценариев**; после финальных исправлений и добавления отдельной проверки страниц повторены **16 сценариев каталога**. Дополнительный сценарий принудительно выбирает 58-й релиз и проверяет отмену запоздавшей второй страницы после нового поиска.

[Живое видео 0.8.1](live-play-0.8.1.json): «Фрирен» в основном и «Клинок, рассекающий демонов» в альтернативном плеере — 1920×1080, декодирование звука и успешная перемотка 60 → 61 секунда. Это реальное видео, без подмены API/медиа.

Результаты полного прогона и Windows-установщика записаны в [validation.md](validation.md). Проверяются быстрый ввод/очистка/Enter, сортировки, несколько фильтров, пустое пересечение, случайный выбор, его отмена, переходы между экранами и провайдерами, отказ загрузки жанров и повтор, малое окно, уменьшение движения и прежние сценарии воспроизведения.

[Живая проверка API](live-filters-0.8.1.json) использует настоящие ответы обоих провайдеров: сочетание жанров/возраста, поиск «Фрирен», случайный выбор и сортировка. [Живой Electron](live-filters-ui-0.8.1.json) подтвердил 24 карточки, фильтр 16+, случайную карточку и открытие точной страницы «Фрирен» в изолированном окне приложения. В повторном прогоне страница сайта не достигла DOMContentLoaded за 20 секунд; это зафиксировано вместе с успешной первой попыткой. Открытие страницы не является проверкой всех её сторонних видеоплееров.

Прокси облачной среды отклонил CDN постеров Yummyani `static.yani.tv` с CONNECT 403. Домен добавлен в черновик настроек сети, применение требует сохранения и публикации окружения. Поэтому загрузка живых постеров этого провайдера в облаке пока не подтверждена; заглушка ошибки не останавливает каталог. Доступность видео из РФ, всех аниме и всех плееров сайта этим прогоном не подтверждается.
