# Фотографии персонажей — Yoru 0.6.2

Карточка использует фотографию своего персонажа из AniDB XML: `<character><picture>`. Рядом с именем сэйю показывается изображение из атрибута `picture` элемента `<seiyuu>`. Допускаются безопасные имена файлов/адреса CDN AniDB; отсутствие или некорректность поля не удаляет сам состав.

В углу фотографии есть кнопка замены. Поиск MyAnimeList через Jikan запускается вручную, ограничен восемью результатами, имеет тайм-аут 10 секунд и кэш до 20 запросов на пять минут. Пользователь проверяет имя и фотографию перед сохранением. Нет автоматического сопоставления разных каталогов по имени. Можно указать собственную HTTPS-ссылку без логина/пароля или вернуть исходное фото. Замена сохраняется по ID персонажа внутри ID релиза; обновление и повторный импорт не стирают её.

Изображения загружаются лениво, без referrer, с обычным HTTP-кэшем приложения. Их доступность зависит от сервера и сети. При отказе показывается нейтральная заглушка с доступной кнопкой замены. Поиск, изображение и ошибки метаданных не перезапускают видео. Фотографии не встраиваются в EXE; тестовые картинки исключены из Windows-пакета. Права на изображения принадлежат их правообладателям.

## Источники и живая проверка 24 октября 2026

- Предоставленный [каталог Yummyani](https://old.yummyani.me/catalog?page=5) и CSS сайта доступны (HTTP 200). Изучены группы кнопок и состояния наведения; в приложении сохранены собственные темы и компактное управление.
- Главная AniDB ответила HTTP 403. Доступность сайта и сервера картинок различается: восемь HTTPS-изображений персонажей/актёров с `cdn.anidb.net` загружены с HTTP 200.
- Для проверяемого примера взят [публичный архив XML AniDB для Arcade Gamer Fubuki, релиз 128](https://github.com/ailev/anird/blob/master/aniDB/data/128.xml). В `test/fixtures/characters/cast.xml` сохранены четыре записи с исходными ID, именами и именами файлов. `images.json` содержит URL и SHA256 каждого загруженного снимка. Это архивные сведения, а не свежий ответ API или подтверждение полного состава сериала.
- Живой Jikan/MyAnimeList в этой облачной сети получил CONNECT 403. Поведение поиска проверено на контролируемых ответах API; работоспособность живого поиска в пользовательской сети здесь не подтверждена. Собственная ссылка и исходные фотографии AniDB доступны независимо от поиска.

Для запроса состава через API AniDB по-прежнему нужен собственный зарегистрированный HTTP-клиент. Импорт XML работает без него. Автоматический полный состав каждой серии не заявляется; ручные отметки подписываются отдельно.

## Проверки

Unit-тесты проверяют безопасные адреса, совместимость старого кэша, проверку источника фотографии, ограничение/отмену/кэш поиска, сохранение замен по ID и отсутствие переноса между релизами. Браузер проверяет загрузку портретов и фото сэйю, явный выбор результата, перезагрузку, обновление состава, возврат исходного снимка и отказ изображения при продолжающемся воспроизведении. Отдельный сценарий показывает настоящие восемь JPEG из архива в мягком интерфейсе и создаёт снимок `anidb-cast.png`.

Настоящий Electron дополнительно проверяет фотографии и ручную замену через `file://`, её сохранение при обновлении API и изоляцию окна AniDB. Эти проверки используют контролируемые сетевые ответы и не заменяют запуск на Windows.
