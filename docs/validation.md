# Проверка перед отправкой на GitHub

## Предварительная версия 0.7.3 — установщик и фирменная иконка

Добавлен автономный NSIS-установщик для Windows 10/11 x64: один EXE, текущий пользователь, без повышения прав, необязательный ярлык рабочего стола, меню «Пуск», регистрация удаления в настройках Windows. Обновление и удаление сохраняют профиль `%APPDATA%\kadr-anime`; удаление перечисляет только поставленные файлы и не очищает папку рекурсивно. Открытый EXE защищён от перезаписи без принудительного завершения просмотра.

Сгенерирована иконка Yoru: мастер PNG, PNG 512 px и ICO 16/24/32/48/64/128/256 px. Все семь изображений внутри упакованного `Yoru.exe` побайтно совпали с ICO. Иконка подключена ко всем окнам приложения, установщику, удалению, ярлыкам и веб-превью. Неиспользуемые языковые пакеты Chromium убраны: русский и английский оставлены; локальная Windows-папка уменьшилась примерно на 47 MiB. Медиа-компоненты не удалялись.

Локально прошли 46 unit-тестов, production-сборка, настоящий Linux Electron и Windows ASAR через Linux Electron. Это не запуск Windows EXE. Браузерные 44 сценария воспроизведения из аудита 0.7.2 в этом изменении повторно не запускались: бизнес-логика и экранные компоненты не менялись.

Проверка на Windows обнаружила неверную кодировку русского текста и отсутствие автоматического перехода к собственной завершающей странице. Исправлены явное чтение UTF-8, включая список удаляемых файлов, и переход к окончанию установки. Тест отличает настоящие кнопки от статической надписи «Готово» в прогрессе. Для проверки ярлыков используется Unicode-интерфейс IShellLinkW: прежний getter WScript.Shell терял кириллицу на англоязычной Windows, хотя сами ярлыки были правильными. Быстрая проверка настоящих NSIS-страниц с небольшим инертным пакетом, включая папку с пробелами и кириллицей, прошла; она не подменяет отдельную проверку полной поставки Electron.

[Windows CI 0.7.3](https://github.com/Duwkaf1/kinoteatr-xivivide/actions/runs/40182999548) завершился успешно на коммите **3cd5aac95b2e7048e3f5bfde8a5ee60552d9a2b2**: оба задания, 46 unit-тестов, сборка, запуск настоящего Windows Electron, упаковка, компиляция NSIS, установка полной поставки, запуск установленного EXE со всеми desktop-проверками, повторная установка, защита работающего приложения, удаление всех поставленных файлов с сохранением профиля и постороннего файла, путь с кириллицей и пробелами, загрузка обоих артефактов. Результаты подтверждены статусами шагов и аннотациями GitHub API; полный архив логов облачной сети недоступен.

[Полный автономный установщик](https://github.com/Duwkaf1/kinoteatr-xivivide/actions/runs/40182999548/artifacts/12594673507): **106 366 394 байта** (101.4 MiB), SHA-256 `05a01abd74e8a4672ad5be96d0d07e0098c9b023345ca3f9182e5a5d70aa6b5b`. Это контрольная сумма самого EXE, не ZIP-обёртки GitHub. [Прежний формат ZIP без установки](https://github.com/Duwkaf1/kinoteatr-xivivide/actions/runs/40182999548/artifacts/12594818250) тоже сохранён. Артефакты Actions имеют ограниченный срок хранения.

[Установка и сборка](installer.md). Прежние ограничения каталогов, живых источников и Discord остаются прежними: установщик их не исправляет. Сборка пока не подписана сертификатом издателя.

## Предварительная версия 0.7.2 — проверка воспроизведения

Убраны подписи источника фото с карточек. Проверка расширена на оба движка, настоящие MP4/WebM/HLS, счётчик декодирования звука, выбор студий/оригинала, HTTP 503 и следующую серию. Найдены и исправлены перенос ложной паузы при смене плеера во время загрузки и очистка libass при переподчинении/удалении video в Video.js. Стресс-сценарий многократно меняет движок с оформленным переводом и затем закрывает плеер; canvas и worker освобождаются без ошибок страницы.

Живые проверки выявили неподтверждённое воспроизведение сайтов и блокировку видеосервера AniLibria. Готовность «все аниме работают без настройки» не установлена; автоматических адаптеров видеокаталогов ещё нет. [Подробный результат и границы проверки](release-audit-0.7.2.md) · [HTTP-отчёт](release-audit-0.7.2.json).

Итог 0.7.2: 46 unit-тестов, 44 браузерных сценария, Linux Electron, Windows ASAR и [Windows CI](https://github.com/Duwkaf1/kinoteatr-xivivide/actions/runs/40177578425) прошли. Найденные ошибки исправлены; общая готовность всех сайтов/озвучек не подтверждена.

## Версия 0.7.0 — полный редизайн

25 октября 2026. Успешно выполнены 45 unit-тестов, 37 браузерных сценариев, production-сборка и настоящий Linux Electron через `file://`. Дополнительно проверены все шесть вариантов оформления, контраст текста готовых тем, клавиатура, контрастные системные цвета, длинные названия, формы и эмуляция масштаба 100/125/150/200%. Настоящий Electron проверяет zoom 100/125/150/200%, границы диалогов, минимальное окно 640×480 и запуск с OLED. Пересняты все 33 PNG галереи.

Windows-папка и ZIP 0.7.0 собраны, целостность ZIP и сигнатура EXE проверены. В `app.asar` подтверждены версия, OLED и новая навигация настроек; тестовые изображения и кэш исключены. Проверка Windows EXE, реального DPI монитора и звука Discord на пользовательском Windows отличается от Linux Electron/эмуляции и здесь ими не подменяется. После публикации исходников [Windows CI](https://github.com/Duwkaf1/kinoteatr-xivivide/actions/runs/40173372346) завершился успешно: установка, unit-тесты, build, настоящий Windows Electron, package, ZIP и upload-artifact. Результат подтверждён статусами всех шагов через GitHub API; полный архив логов недоступен из облачной сети. Прямое прикрепление ZIP к Releases также отклонено сервером загрузки, поэтому релиз ссылается на успешный Windows artifact.

Пользователь явно разрешил загрузить исходники в текущий открытый репозиторий. Для этой версии подготовлена публикация всего приложения, README и новой галереи. Прежние ограничения публикации, описанные ниже, относятся к прошлым версиям. [Отчёт о редизайне](redesign-0.7.md).

## Локальная версия 0.6.3 — имена и заметки для каждого аниме

25 октября 2026. Пройдены 44 unit-теста, 33 браузерных сценария и настоящий Electron через `file://`. Новые проверки подтверждают независимые личные подписи двух аниме с одним AniDB ID, отдельный релиз сезона, обновление XML без потери записей, возврат исходного имени с сохранением заметки, перезагрузку, отказ записи с сохранением текста в поле и успешную повторную запись. Заметки сохраняются независимо от вытеснения AniDB-кэша. На карточке видны редактируемое имя и поле заметки сразу под ним; видео не перезапускается при редактировании.

Windows ZIP версии 0.6.3 собран и проверен на целостность, версия и окно редактора внутри `app.asar` подтверждены. Этот же ASAR успешно прошёл desktop-сценарий в Linux Electron; запуск Windows EXE и звук Discord на Windows не проверены. Проверки не означают автоматическую загрузку всего каста библиотеки: для каждого аниме/сезона нужны данные правильного релиза AniDB. Репозиторий остаётся публичным, поэтому на GitHub публикуются документация и изображения; новые исходники сохраняются локально. [Подробности хранения](character-details.md).

## Первоначальная версия 0.2.0

24 октября 2026 года. Версия приложения: 0.2.0.

В текущей Linux-среде выполнены и завершились успешно:

- `npm ci` — установка по lockfile.
- `npm test` — 9 тестов логики, импорта и хранения данных.
- `npm run build` — production-сборка. Есть предупреждение о размере отдельного HLS-модуля; он загружается только по необходимости.
- `npm run test:e2e` — 12 браузерных сценариев, включая реальный синтетический WebM/HLS, переключение источника, русский язык, качество, следующую серию, библиотеку на 500 записей, отключение эффектов и горячие клавиши.
- `DISPLAY=:97 NODE_USE_ENV_PROXY=1 KADR_ELECTRON_NO_SANDBOX=1 npm run test:desktop` — настоящий Electron с виртуальным Xorg-дисплеем. Загружены production-файлы через `file://`, проверены preload/IPC, отсутствие Node.js в страницах, отдельное окно источника без bridge, добавление и сохранение библиотеки, воспроизведение собственного WebM и закрытие приложения вместе с источниками. Отключение Linux sandbox используется только в изолированном тестовом запуске; продукт сохраняет `sandbox: true`.

Во время проверки исправлено закрытие окна источника до окончания загрузки: обработчик ошибки больше не вызывает метод уже уничтоженного окна. Закрытие главного окна также закрывает окна источников. Отдельный `--user-data-dir` позволяет тестировать, не затрагивая пользовательский профиль.

Windows-пакет создаётся с официальной проверкой контрольных сумм Electron. Архив проверяется `ZipFile.testzip`, наличие Windows EXE проверяется по сигнатуре, рядом записывается SHA256. Это проверка упаковки, не доказательство запуска EXE на Windows.

Добавлен workflow `Verify and build Windows`: после push в main он должен запустить unit/desktop-проверки на windows-latest и сохранить ZIP как artifact. Его фактический результат необходимо смотреть в Actions. Наличие workflow не означает успешного прогона. Перед отправкой GitHub API из облачной среды ответил Forbidden, поэтому результат удалённого CI здесь не подтверждён.

Живые источники проверены отдельно после применения сетевой политики:

- `https://g0e-1ka1v5q.troutcdn.site/283290` — HTTP 403 с HTML-ответом.
- `https://brogiro.cfd/series/283290/` — HTTP 404 с HTML-ответом.

Причины HTTP-ответов не установлены. Это не доказывает недоступность страниц с пользовательского VPN. Воспроизведение с них, каталоги и автоматическое управление их плеерами не реализованы и не считаются прошедшей проверкой. Настоящий звук и демонстрация Discord на Windows также не проверены.
