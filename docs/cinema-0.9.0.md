# Yoru 0.9.0 — фильмы и сериалы

В каталоге появились три раздела: **Аниме / Фильмы / Сериалы**. Аниме, его провайдеры, озвучки и субтитры сохранены. Фильмы и сериалы добавляются в общие избранное и библиотеку.

## Поиск и сервисы

Cinemeta предоставляет названия, описания, жанры, год, постеры и список серий. Запросы соответствуют публичному протоколу [Stremio metadata](https://github.com/Stremio/stremio-addon-sdk/blob/master/docs/api/responses/meta.md) и [catalog handler](https://github.com/Stremio/stremio-addon-sdk/blob/master/docs/api/requests/defineCatalogHandler.md). Жанры читаются из manifest выбранного каталога. Поиск некоторых названий лучше работает на языке оригинала. Это каталог метаданных, не список подтверждённых видеопотоков.

Если Cinemeta не отвечает, для сериалов запрашивается **TVmaze**, для фильмов — **Internet Archive** с указанной свободной лицензией. Смена каталога явно обозначается. Резерв может содержать другой набор названий. Совпадение названия не используется для подмены карточки: детали должны вернуть запрошенный IMDb ID, TVmaze ID или Archive identifier. Страница из 24 карточек корректно пересекает границу провайдерской страницы в 100 элементов. Сеть имеет тайм-ауты, ограничение размера ответа, отмену устаревших запросов и ограниченный кэш.

В карточке доступны **«Найти на YouTube / Кинопоиск / Rutube / VK Видео»**. Открывается официальный поиск в системном браузере с названием, годом, выбранным сезоном и серией. Доступ к полной версии, вход, оплата и региональные ограничения определяются сервисом. Приложение не выдаёт поиск за готовый поток и не извлекает защищённое видео. Браузер используется для корректной работы авторизации и DRM. При отказе метаданных введённое название всё равно можно искать на выбранном сервисе.

**Между этими сайтами нет автоматического переключения с сохранением позиции и озвучки:** они не предоставляют Yoru единый интерфейс управления воспроизведением. Выбрать другой сервис можно вручную. Время и история просмотра в браузере не синхронизируются с Yoru.

## Прямой просмотр свободных фильмов

Для Internet Archive встроенная кнопка просмотра появляется при совпадении identifier карточки, явно указанной разрешённой лицензии, известном языке и подходящем MP4 с MD5, разрешением 480/720/1080 и длительностью более десяти минут в метаданных. Список лицензий ограничен PDM 1.0, CC0 1.0, CC BY 4.0 и CC BY-SA 4.0. Приложение опирается на метаданные загрузчика; они не заменяют проверку правообладателя. При отсутствии нужных данных остаётся страница Internet Archive.

Резервные адреса строятся только для **того же имени файла и MD5**, разрешения и звуковой дорожки на серверах Archive, указанных его API. Другой фильм, монтаж, качество или озвучка не подставляются. Ошибка загрузки и ожидание без продвижения видео используют существующее восстановление плеера. Пауза пользователя не считается сбоем. Встроенная история сохраняет время; после обновления метаданных оно восстанавливается только для того же файла. Язык показывается по метаданным, русская озвучка не приписывается английской дорожке.

## Соединение и регион

**Настройки → Дополнительно → Доступ к видеосервисам → Проверить соединение с сервисами** проверяет фиксированные публичные страницы с ограничением времени и без передачи учётных данных. Результат различает доступную страницу, ограничение/необходимость входа и неподтверждённое соединение. Это не тест воспроизведения выбранного фильма и не географическая гарантия. VPN-расширение браузера может использовать другую сеть, чем само приложение.

В текущей облачной среде соединения с новыми доменами были отклонены прокси на этапе CONNECT (403). Сетевой черновик с необходимыми доменами сохранён, но ещё не опубликован пользователем; действующая политика остаётся revision 6. Российского выхода и выходов в другие страны у среды нет. Проверка реального Cinemeta/TVmaze/Archive, воспроизведения фильмов на YouTube/Кинопоиске и их доступности в РФ/других странах **не завершена**. CI не используется для обхода сетевой политики.

## Воспроизводимые проверки

87 unit-тестов и production-сборка прошли. Шесть новых браузерных сценариев проверяют разделы, быстрый поиск/смену вкладок, отмену старых ответов, избранное, точную серию в ссылке, отказ метаданных, повтор, Ctrl+K, узкое окно, резерв одного файла и восстановление позиции. Полный итог браузерного и Windows-прогонов публикуется в README и истории проверок после завершения.

Настоящий Linux Electron успешно проверил новые типизированные IPC, открытие выбранного сервиса и точной серии, диагностику страниц, реальное декодирование H.264/AAC 1920×1080, отказ основного адреса и резерв того же файла, сохранение двух секунд и продолжение после перезапуска. Ответы новых каталогов и сайтов в этих сценариях контролируются тестом. Собственный короткий MP4 проверяет медиадвижок, а не доступность полнометражного фильма. В тестовых метаданных длительность намеренно задана для прохождения отбора; файл не включается в установщик.

Скриншоты новых экранов используют контролируемые данные; у недоступных постеров показана заглушка, чужие обложки не подставлены. Старые живые снимки аниме 0.8.2 остаются историческими и не являются подтверждением работы новых киносервисов.
