# Постеры локальной версии Yoru 0.5

Эта функция реализована в локальной версии 0.5. В публичной ветке `main` пока остаётся код 0.2 без этой функции; здесь опубликованы описание и снимки интерфейса.

Источник — публичный каталог AniLibria: [документация API V1](https://anilibria.top/api/docs/v1). Проверены HTTPS-поиск, данные релизов и загрузка WebP-постеров 24 октября 2026 года. Ключ и регистрация для этих запросов не потребовались.

Поиск: `GET https://anilibria.top/api/v1/anime/catalog/releases?f[search]=Фрирен&limit=8`. Из ответа читаются `id`, `name.main`, `name.english`, `year`, `poster.optimized.preview` либо `poster.preview/src`. Относительная ссылка разрешается относительно `https://anilibria.top`; для результатов каталога принимаются только его изображения в `/storage/releases/posters/`. Не строим имя файла по названию и не подставляем первый результат: нужный сезон выбирает пользователь.

В импорте необязательны:

```json
{
  "posterUrl": "https://anilibria.top/storage/releases/posters/9542/8UGD4dHHp1kdjquBph2CUSk9pLNsGtYw.webp",
  "anilibriaId": 9542
}
```

Это дополнительные поля записи аниме, а не полный файл импорта. `posterUrl` — HTTPS-ссылка до 2048 символов без логина и пароля. `anilibriaId` указывается только для действительно выбранного релиза AniLibria, положительным числом и вместе с его URL. Для своей картинки достаточно `posterUrl`. Полный пример: [playlist.example.json](playlist.example.json). Старые списки без этих полей продолжают работать.

Поиск выполняется только по кнопке: максимум восемь результатов, таймаут 10 секунд, без автоматических повторов. При смене запроса и закрытии окна запрос отменяется, запоздалый ответ не заменяет новый выбор. До 24 последних запросов сохраняются в памяти на пять минут. Изображения используют `loading=lazy`, `decoding=async`, `referrerpolicy=no-referrer`, фиксированные пропорции и штатный HTTP-кэш. Собственного гарантированного офлайн-хранилища постеров пока нет. Изображение может стать недоступным у поставщика; ссылка меняется через «Обложка».

Постеры загружаются отдельно от видео и не участвуют в переключении источников. При ошибке — нейтральная заглушка и доступный запуск серии. Рендер библиотеки сам не запускает поиск по названиям; импортированные ссылки сохраняются при перезапуске. Видеопотоки каталога этой функцией не подключаются.

Обложки на скриншотах получены из этого API; права на изображения принадлежат их правообладателям. Точные URL, ID релизов, год и SHA256 тестовых копий записаны в `test/fixtures/posters/catalog.json`. Тестовые изображения не входят в Windows-дистрибутив. Снимки интерфейса воспроизводятся из сохранённых ответов, поэтому тесты не зависят от текущей доступности каталога.

Проверки: unit — валидация/хранение, адреса, отмена, кэш и ошибки; Chromium — выбор, отмена, удаление, перезапуск и воспроизведение при ошибке постера; Electron — выбор через реальный `file://` интерфейс, CSP, сохранение и запуск видео. Живой HTTPS API и файлы проверены средствами среды с TLS. Прямая внешняя загрузка в облачном Chromium блокируется отсутствием сертификата прокси в его хранилище; проверка TLS не отключалась. Живой поиск на пользовательском Windows/VPN ещё нужно проверить.
