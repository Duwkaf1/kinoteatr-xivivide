# Quality-mode loading artwork

`miku-dance.png` is an original generated pixel-art fan illustration requested for Yoru, arranged as eight frames (4 columns × 2 rows). Hatsune Miku is a character of Crypton Future Media; this is an unofficial fan illustration, with no endorsement implied. The image was generated for this project; it was not extracted from an anime or copied from a sprite pack.

The app assigns this asset only while video is waiting in Quality mode with motion enabled. CSS steps select the eight frames. Playback, pause, closing the player, reduced motion and leaving Quality mode stop the animation. Other modes do not request this artwork. The generated original remains in the workspace's generated_images folder.
