Как работает восстановление

Для прямых видеоссылок: повторная попытка, затем другой источник той же серии. Выбранное качество сохраняется. При смене озвучки появится сообщение. При полном отказе источников воспроизведение остановится с объяснением.

Ссылка на страницу сайта не является прямой ссылкой на видео. Для каждого сайта нужен проверенный адаптер.

Свой буфер и библиотека

Буфер относится к HLS-видео. Его размер не равен всей памяти приложения. Маленький буфер может чаще останавливаться на нестабильном интернете.

От 5 до 90 секунд. Больше — выше расход памяти, но больше запаса видео.

От 0 до 30, не больше буфера вперёд. Помогает перематывать уже просмотренный фрагмент.

От 8 до 128 МиБ. Фактический размер зависит от потока и длительности сегментов.

Меньше карточек — легче интерфейс. Поиск охватывает всю библиотеку.

Восстановление и озвучки

Если отключить, приложение завершит попытки на первом источнике и покажет сообщение.

Сначала выбранная студия, затем вторая. Применяется в режиме русской озвучки.

Если отключить, останутся только AniDUB и AniLibria / AniLiberty.

Персонажи и сэйю · AniDB

Связь с AniDB задаётся отдельно для каждого сезона. Персонажи и актёры озвучивания не зависят от выбранного перевода.

Отметить персонажей текущей серии

AniDB XML содержит общий состав релиза и не даёт полный состав каждой серии. Можно отметить его вручную; такие отметки будут подписаны отдельно.

Подключение HTTP API AniDB

Для API нужны зарегистрированное в AniDB имя HTTP-клиента и версия. Это не логин и не пароль. Без клиента можно открыть сайт или импортировать XML.

Демонстрация в Discord

В установленном Discord выбери демонстрацию окна «Yoru» и включи передачу звука. Плеер использует обычный аудиовыход Windows. Не транслируй весь экран, если нужен только звук приложения.

Захват звука и изображения ещё нужно проверить на Windows. При проблемах с аппаратным ускорением запусти приложение с параметром --disable-gpu.
